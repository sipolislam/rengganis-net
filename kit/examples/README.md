# Contoh: CatatKas

`catatkas/` adalah proyek web nyata-tetapi-kecil untuk menunjukkan **kedalaman dan kekhususan** yang diharapkan dari model.

| File | Fungsi |
|---|---|
| `SPEC.json` | Contoh SPEC lengkap yang valid terhadap skema |
| `docs/PRD.md` | Fitur F1–F6 dengan acceptance yang dapat diuji; refleksi mahasiswa dikutip persis |
| `docs/TASKS.md` | 14 task S–L, tiap fitur terpecah, dependensi dan kriteria selesai yang bisa dicek |
| `AGENTS.md` | AGENTS.md ringkas (±80 baris), perintah, batasan Always/Ask/Never |

Cara memakai: (1) beri model contoh ini sebagai acuan gaya bila hasilnya terlalu generik; (2) bandingkan keluaran model dengan contoh memakai `RUBRIC.md` Bagian B; (3) `tools/selftest.py` memakai contoh ini untuk menguji validator.

Contoh ini hanya mencakup tiga dokumen terisi. 13 dokumen lain dibentuk dari template; lihat tiap template untuk instruksi isi.
